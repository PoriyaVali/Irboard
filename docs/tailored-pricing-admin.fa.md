# مدیریت قیمت‌گذاری تعرفهٔ دست‌دوز

این قابلیت در پنل Laravel و تب مستقل **«دست‌دوز»** قرار دارد؛ این تب در منوی
کناری، درست زیر **«مدیریت اشتراک‌ها»** نمایش داده می‌شود. مسیر آن
`#/tailored-pricing` است. جدول تعرفه‌ها و ویرایشگر فعلی آن‌ها در تب مدیریت
اشتراک‌ها باقی می‌مانند و ورود به آن تب، تنظیمات دست‌دوز را بارگذاری نمی‌کند.

## انتخاب و اصلاح مراجع

۱. نوع هر تعرفه را مشخص کنید: «تعیین‌نشده»، «حجم کل محدود، بدون شارژ مجدد»
یا «نامحدود / مصرف منصفانه». نام و عدد حجم به‌تنهایی نوع تعرفه را مشخص نمی‌کنند.

۲. هر **تعرفه و دوره** را جداگانه انتخاب کنید؛ مثلاً ۳۵ گیگ برای ۳۰ روز
می‌تواند انتخاب شود و دورهٔ ۹۰روزهٔ همان تعرفه انتخاب نشود. فقط تعرفه‌های
حجمیِ صریحاً تأییدشده و بدون بازنشانی حجم قابل انتخاب هستند.

۳. علت غیرقابل انتخاب بودن هر ردیف نمایش داده می‌شود. نامحدود، مصرف منصفانه،
شارژ مجدد، قیمت نامعتبر، حجم خارج از محدوده، تعرفهٔ مخفی یا دارای محدودیت
ظرفیت فروش مرجع نمی‌شوند. مراجع منتخب باید گروه دسترسی، سرعت و تعداد دستگاه
سازگار داشته باشند؛ منابع ناسازگار به‌صورت خودکار ترکیب نمی‌شوند.

۴. برای تغییر مبلغ اصلی، به ویرایشگر تعرفه در تب **مدیریت اشتراک‌ها** بروید؛
سپس به تب دست‌دوز برگردید و تنظیمات را دوباره دریافت کنید. این بخش قیمت جداگانه‌ای برای تعرفه‌ها
نگهداری نمی‌کند؛ قیمت واقعی Laravel مبناست.

## مدل، پیش‌نمایش و نمودارها

دکمهٔ «پیش‌نمایش تغییرات» مدل پیش‌نویس را محاسبه می‌کند و هیچ تنظیمات، سفارش
یا برداشت مالی ثبت نمی‌کند. صفحه این موارد را نشان می‌دهد:

- مراجع انتخاب‌شده، ضریب پایهٔ محاسبه‌شده و فرمول ثابت؛
- قیمت واقعی هر مرجع، قیمت مدل برای همان نقطه و درصد اختلاف؛
- منحنی قیمت برحسب حجم و منحنی قیمت برحسب مدت؛
- کنترل حجم و روز برای بررسی نقاط مختلف، با نمایش دلار و تومان؛
- تفاوت روشن بین مدل ذخیره‌شده و پیش‌نویسِ ذخیره‌نشده.

فرمول ثابت است و فقط ضریب پایهٔ A از مراجع انتخاب‌شده محاسبه می‌شود:

```text
P(d,t) = A × ((d + 150) / 185)^1.13 × (t / 30)^0.20
A = میانهٔ نسبت قیمت دلاری هر مرجع به ضریب فرمول در همان حجم و مدت
```

حجم بین ۱ تا ۱۰۲۴ گیگ و زمان بین ۱ تا ۳۶۵ روز است. حجم برای **کل دوره** است
و ماهانه شارژ نمی‌شود. قیمت دلاری ثبت‌شده اولویت دارد؛ در نبود آن، قیمت واقعی
تومانی با نرخ تبدیل فعلی استفاده می‌شود. تبدیل به تومان و پایین‌گردکردن به
هزار تومان طبق منطق فعلی حفظ شده است. ویرگول جداکنندهٔ هزارگان است.

## ذخیره و حالت‌های خاص

پس از بررسی پیش‌نمایش، «ذخیره تنظیمات تأییدشده» را بزنید. تا پیش از ذخیره،
تغییر انتخاب‌ها روی قیمت کاربران اثر ندارد. هیچ مرجعی به‌طور پیش‌فرض تأیید
نیست و بدون مرجع معتبر، خرید دست‌دوز فعال نمی‌شود.

اگر ادمین دیگری تنظیمات را ذخیره کند یا قیمت تعرفه‌ها هنگام ویرایش عوض شود،
صفحه پیش‌نویس شما را حفظ می‌کند و دریافت دوبارهٔ تنظیمات را لازم می‌داند؛
تنظیمات جدید را بی‌صدا بازنویسی نمی‌کند. هنگام دریافت دوباره، کنارگذاشتن
تغییرات ذخیره‌نشده از خود صفحه قابل کنترل است.

اگر تعرفهٔ منتخب حذف شود، از فهرست «تعرفه و دوره‌های انتخاب‌شده» مرجع قدیمی
را حذف و تنظیمات را اصلاح کنید. با حذف یا نامعتبر شدن مرجع، تعرفهٔ دیگری
خودکار جای آن قرار نمی‌گیرد. سفارش جدید با پیش‌فاکتور قدیمی باید دوباره
قیمت‌گذاری شود؛ تکرار پاسخ سفارش پرداخت‌شده برداشت دوباره ایجاد نمی‌کند.

دسترسی این بخش مخصوص ادمین است. پیش‌نمایش مرورگر و تست‌ها از دادهٔ آزمایشی
استفاده می‌کنند و به معنای استقرار روی محیط اصلی نیستند. انتشار عمومی اپ
همچنان متوقف است؛ استقرار مجاز Laravel و آزمایش آن، عملیات جداگانه‌ای هستند.

## نگهداری منو و مسیر

منو، مسیر و ماژول React در هر دو فایل `umi.js` و `umi-fa.js` با سه بخش مشخص‌شده
ثبت می‌شوند. منبع قابل نگهداری صفحه `scripts/admin_tailored_pricing.js` است و
ماژول `irboard/tailored-pricing` مستقیماً کامپوننت مسیر Umi را صادر می‌کند.
چیدمان اصلی پنل، جدول و کنترل‌های Ant Design از همان runtime پنل استفاده
می‌کنند. نمایش صفحه با state و چرخهٔ عمر React انجام می‌شود؛ اسکریپت مستقل،
میزبان DOM، MutationObserver و جابه‌جایی دستی عناصر حذف شده‌اند. فایل CSS فقط
چیدمان اختصاصی قیمت‌گذاری و نمودارهای SVG را تکمیل می‌کند.

اسکریپت `scripts/patch_admin_tailored_pricing.py` این سه افزودن را به‌صورت
تکرارپذیر انجام می‌دهد و خارج از بخش‌های متعلق به خود، هیچ بایتی را تغییر
نمی‌دهد. پس از ویرایش منبع، نسخه‌های پنل را تولید و بررسی کنید:

```sh
python scripts/patch_admin_tailored_pricing.py
python scripts/patch_admin_tailored_pricing.py --check
node --check scripts/admin_tailored_pricing.js
node --test tests/AdminTailoredPricingBrowserTest.cjs
```

برای پنل دارای تغییرات اختصاصی، اسکریپت باید روی کپی همان فایل‌های واقعی
اجرا شود؛ جایگزینی کامل فایل‌های محیط اصلی با نسخهٔ مخزن، تغییرات اختصاصی
را حفظ نمی‌کند. اسکریپت، مسیر فایل‌ها را هم به‌صورت آرگومان می‌پذیرد و در
صورت مبهم بودن محل افزودن، پیش از نوشتن فایل‌ها متوقف می‌شود.

تست مرورگر هر دو bundle واقعی را در Chromium باز می‌کند و ورود از منو،
کنترل‌های بومی، انتخاب صریح مرجع/دوره، پیش‌نمایش قبل از ذخیره، تعارض نسخه،
تغییر نشست و مسیر، نمودارهای دلار/تومان، اعداد فارسی و نمایش موبایل را بررسی
می‌کند. تغییر حجم و مدت در نمودار فقط پیش‌نمایش محلی است و قیمت ذخیره‌شده را
تغییر نمی‌دهد. فرمول، مبنای محاسبه و API قیمت‌گذاری سمت سرور تغییر نکرده‌اند.
